# Astral Express

A fast-paced 2D action platformer built with **Godot Engine 4**. Battle through enemies, manage your ammo, and reach the portal to advance through each stage while aiming for the highest score.

## Features
* **360° Mouse Aiming & Shooting:** Aim freely with your cursor and fire projectiles with reload and magazine management.
* **Multi-Level Progression:** Fight your way to the exit portal at the end of each level to advance.
* **Health & Invincibility Frames:** Take hits with brief post-damage invulnerability to recover and reposition.
* **Persistent Score System:** Rack up points across levels and view your final run score on the death screen.
* **Custom Audio & Loopable Soundtrack:** Dynamic sound effects for shooting and stage transitions backed by continuous music.

## Controls
| Action | Input |
| :--- | :--- |
| **Move Left / Right** | `A` / `D` or `Left` / `Right` Arrow |
| **Jump** | `Space` / `W` / `Up` Arrow |
| **Aim** | Mouse Cursor |
| **Shoot** | `Left Click` |
